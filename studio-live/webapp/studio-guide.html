1. Démarrer

  1. Décompresse entièrement le dossier téléchargé. Ne lance pas le programme à l’intérieur du ZIP.
  2. Ouvre Demarrer-Interface-Studio.cmd ou App Interface Studio.exe. Aucun Node.js à installer pour cette version Windows.
  3. Clique sur Ouvrir une application et sélectionne ton APK. Les ressources sont copiées dans un projet de travail. L’APK original n’est pas directement modifié.
  4. Choisis Édition, Exécution Android ou Côte à côte. L’éditeur et Android sont dans la même fenêtre.
VueUsage
ÉditionModifier les objets et les fichiers disponibles dans l’application.
Exécution AndroidLancer et piloter l’APK installé sur un émulateur ou un appareil connecté.
Côte à côteComparer les ressources à gauche et l’application exécutée à droite. Sur une petite fenêtre, les outils latéraux sont masqués : reviens à Édition pour les utiliser.

2. Utiliser Android sans téléphone branché

  1. Installe une fois Android Studio sur Windows.
  2. Dans son SDK Manager, installe Android Emulator, Platform-Tools, Build-Tools et une image système x86_64 compatible avec ton APK.
  3. Crée un téléphone virtuel dans Device Manager. Si tu veux retrouver ton smartphone, règle sa résolution et sa densité ; un profil générique peut produire un autre rendu.
  4. Dans Interface Studio, choisis Exécution Android → Configurer Android. Choisis le dossier SDK si Studio ne trouve pas l’émulateur.
  5. Choisis ton appareil virtuel et clique sur Démarrer l’émulateur.
  6. Si aucun APK n’est sélectionné, choisis ton fichier. Clique sur Installer et afficher cet APK.
  7. Ferme les réglages avec Configurer Android pour agrandir l’écran. Clique dans le téléphone pour toucher ; glisse pour faire défiler.

Le SDK minimal fourni sert aux outils APK et à ADB. Il n’inclut pas une image système ni l’émulateur complet. Les données et les photos de ton smartphone ne sont pas automatiquement copiées dans l’émulateur. Certaines fonctions matérielles ou services Google peuvent différer.

3. Reproduire un bouton masqué en bas

Le même APK peut s’afficher différemment si la largeur logique, la hauteur, la densité ou les barres Android ne correspondent pas.

  1. Dans l’exécution Android, clique sur Même écran dans l’éditeur. Studio récupère les dimensions logiques et la taille des barres de l’appareil sélectionné, y compris s’il s’agit d’un émulateur.
  2. Dans la barre supérieure de Studio, règle Barres Android → Superposées au contenu si les commandes Android recouvrent le bas. Utilise Entre les barres lorsque l’application réserve leur espace.
  3. Dans Écran et Android → Écran, garde Afficher les limites Android pendant l’édition activé. Choisis aussi 3 boutons ou Gestes selon l’appareil.
  4. Sans câble, envoie une capture de ton smartphone au PC, puis utilise Calibrer depuis une capture. Indique la largeur en pixels CSS et ajuste les deux lignes sur les limites des barres. La résolution physique seule ne permet pas de déduire la densité.
  5. Compare le même écran et, si possible, les mêmes données. Ajuste le contenu de l’application puis exporte et teste l’APK.

Le profil de barres importé de l’APK est une indication. Vérifie le réglage observé sur Android. Studio ne peut pas garantir un rendu identique à un téléphone dont la densité ou les réglages sont inconnus.

4. Modifier la page

  1. Reviens à Édition. Pour un APK natif, choisis l’édition des ressources si une page de choix s’affiche.
  2. Clique sur l’objet à modifier, ou retrouve-le dans Calques.
  3. Choisis une catégorie puis ouvre son panneau. Le bouton ? affiche son explication ; le survol affiche aussi une infobulle.
  4. Pour une retouche visuelle, utilise Texte, Apparence ou Image. Pour changer l’organisation, utilise Alignement, Espacements ou Flex / Grid.
  5. Avant une modification structurelle, utilise le diff du code source pour examiner ce qui sera réellement changé.
  6. Conserve un point de contrôle et enregistre le projet.

L’aperçu web et les ressources XML ne lancent pas toute la logique native Android. Les contenus dynamiques, comptes et photos personnelles doivent être vérifiés dans Exécution Android.

5. Tester tes changements sur Android

  1. Choisis Projet → Enregistrer pour conserver le travail d’édition.
  2. Choisis APK → Exporter APK signé. Les modifications visuelles applicables sont reportées dans les ressources avant la reconstruction. Attends le message de réussite.
  3. Reviens à Exécution Android ou Côte à côte. L’export disponible est sélectionné lors de l’ouverture depuis le projet. Vérifie le nom du fichier, sinon choisis-le manuellement.
  4. Clique sur Installer et afficher cet APK, puis refais le parcours de l’application.
  5. Si Android indique une signature différente, utilise ta clé originale ou un émulateur dédié sans la version originale. Studio ne désinstalle pas automatiquement une application.

Sauvegarder le projet ne change pas un APK installé. Il faut reconstruire puis installer l’export. Les changements de code Android exigent eux aussi une reconstruction.

7. Modifier Interface Studio lui-même

  1. Enregistre d’abord ton projet.
  2. Dans le menu Windows de Studio, choisis Développement → Modifier Interface Studio.
  3. Choisis un fichier et modifie le code. visual-editor.html contient aussi le fonctionnement de la fenêtre principale ; studio-workspace.css et studio-workspace.js définissent la plateforme unifiée.
  4. Clique sur Sauvegarder et voir ou utilise Ctrl+S. Le CSS se recharge sans fermer l’interface. Le HTML et le JavaScript rechargent la fenêtre.
  5. Utilise Annuler la sauvegarde pour revenir à la version précédente. Une modification concurrente bloque la sauvegarde plutôt que d’écraser l’autre version.

Les fichiers modifiables sont dans resources/webapp. Le programme Electron est dans resources/app ; une modification de ce programme demande de fermer et relancer Studio.

Synchronisation avec l’assistant

  1. Clique sur Synchronisation, en bas à gauche. Les mises à jour du logiciel sont reçues automatiquement depuis la branche feature/interface-studio-live.
  2. Pour publier tes modifications, crée sur GitHub un jeton limité au dépôt Wokgui/Radio-intelligente avec Contents : Read and write, puis colle-le dans Studio, jamais dans le chat.
  3. Après connexion, la publication automatique est activée. Tu peux aussi utiliser Actualiser et Publier maintenant. En cas de conflit, choisis explicitement la version à garder ; une sauvegarde locale est créée.
  4. Enregistre ton projet avant toute actualisation. Les changements du programme interne demandent une relance ; Studio l’indique.

Le dépôt est public. Seuls les fichiers du logiciel sont partagés. Les projets, APK, captures et comptes restent sur ton PC. La synchronisation permet à l’assistant de retrouver tes fichiers lors d’une demande ; elle ne diffuse pas ton écran et n’exécute pas la conversation en continu.

Vérifier le rendu sur ton Windows

  1. Ouvre ton APK dans Exécution et démarre un émulateur ; aucun téléphone USB n’est nécessaire.
  2. Dans le laboratoire Android, clique sur Même écran dans l’éditeur pour mesurer le profil actif.
  3. Choisis Côte à côte et compare la zone basse, les dimensions, les gestes et les trois boutons. Sélectionne Superposé pour reproduire le masquage par les barres.
  4. Dans Synchronisation, clique sur Exporter le diagnostic. Un rapport JSON et une capture PNG sont enregistrés sur ton PC. Tu peux les joindre au chat pour vérifier les écarts ; ils ne sont pas publiés sur GitHub.

8. Résoudre les problèmes courants

Je ne vois pas mes changements dans l’émulateur.
Exporte un nouvel APK et installe cet export. Vérifie le fichier sélectionné dans l’exécution.
L’émulateur ne démarre pas.
Vérifie Android Emulator, l’image système, la virtualisation et l’accélération dans Android Studio. Actualise ensuite Studio.
La partie basse diffère encore.
Compare les dimensions logiques, les barres, la navigation Gestes / 3 boutons, le thème, la taille de texte et la version Android. Le profil importé n’est pas une mesure du téléphone.
L’APK ne peut pas être modifié visuellement.
Certaines applications natives ne fournissent pas de mise en page éditable. Les ressources disponibles restent inspectables et l’exécution Android reste le contrôle de référence.
Les échanges de cette conversation n’apparaissent pas.
Recharge la conversation dans ChatGPT si elle affiche « Connexion interrompue ». Cette mise à jour de Studio ne répare pas la connexion de ChatGPT Desktop.
