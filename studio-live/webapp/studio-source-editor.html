Modifier Interface Studio

Ces fichiers définissent l’éditeur lui-même. Sauvegarde ton projet d’interface avant de modifier le code : les fichiers HTML et JavaScript rechargent sa fenêtre. Les couleurs et tailles CSS changent sans recharger.

Chargement…

Où modifier quoi ?

studio-workspace.css : couleurs, tailles et espacements de la plateforme. studio-workspace.js : onglets, catégories et tutoriel. visual-editor.html : structure et logique de la fenêtre principale. visual-editor.js / css : moteur de sélection et poignées dans l’application. Ctrl+S sauvegarde le fichier. Une copie de la version précédente est conservée. Les modifications externes concurrentes sont détectées.

Cette fenêtre n’établit pas une connexion avec la conversation ChatGPT. Pour que l’assistant travaille sur ta version locale, partage les fichiers modifiés ou synchronise-les avec un dépôt.
