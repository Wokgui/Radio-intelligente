Configurer Android sur Windows

Installer Android Studio officiel. Dans SDK Manager, installer Platform-Tools, Build-Tools, Android Emulator et une image système x86_64 adaptée. Dans Device Manager, créer un téléphone, une tablette ou une Android TV.

Pour TV, choisir une image Android TV / Google TV. Pour les services Google, choisir une image Google APIs ou Google Play appropriée.

Configurer l’accélération Windows

Studio conserve les appareils et leurs données. Aucun téléchargement, effacement ou changement Windows automatique.

2. Lancer votre application

Sans téléphone : sélectionner un appareil virtuel, démarrer l’émulateur, puis installer et afficher l’APK. Android Studio et une image Android installée sont nécessaires une fois.

Utiliser aussi un téléphone réel

Connexion sans câble : Android 11 ou plus récent, PC et téléphone sur le même Wi-Fi. Sur le téléphone : Options pour les développeurs → Débogage sans fil → Associer avec un code. Les ports d’association et de connexion sont différents.

Alternative USB : pour voir votre application, ses données et les barres Android, brancher le téléphone en USB, activer le débogage USB et autoriser ce PC. Choisir le téléphone connecté, puis activer l’écran. Aucun APK à réinstaller pour ce miroir.

Créer un appareil dédié à Studio
L’installation met à jour le même package si sa signature correspond. Une signature différente reste bloquée pour conserver les données. Un APK inconnu peut accéder au réseau et aux données de cet appareil virtuel : utiliser un appareil dédié.

3. Télécommande et clavier

Dans l’écran : clic = toucher, glisser = balayage. Flèches, Entrée et Échap pilotent la télécommande. Flux vidéo Android H.264 avec fréquence réelle affichée. Le son reste dans l’émulateur. Un mode captures est disponible en secours.
